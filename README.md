# Champions League Old and New Format Analysis / Analyse des alten und neuen Champions-League-Formats

## English Version

## Project Overview

This project analyzes and visualizes the old and new UEFA Champions League tournament formats.

The main goal is to compare structural differences between the previous group-stage format and the new league-phase format. The analysis is implemented in Jupyter Notebooks and focuses on understanding how the tournament structure changes and how these changes can be visualized.

## Motivation

The UEFA Champions League introduced a new tournament format starting from the 2024/25 season. Instead of the traditional group-stage structure, the competition now uses a league-phase system.

This project was created to explore these changes from a data analysis and visualization perspective.

## Research Focus

The project addresses questions such as:

* How does the old Champions League format differ from the new format?
* How can both formats be represented and compared visually?
* What structural changes occur in the tournament setup?
* How can football tournament data be analyzed using Python and Jupyter Notebooks?

## Project Files

* `ChampionsLeagueOldFormat.ipynb`
  Analysis and visualization of the old Champions League format.

* `ChampionsLeagueNewFormat.ipynb`
  Analysis and visualization of the new Champions League format.

## Technologies Used

* Python
* pandas
* matplotlib
* seaborn
* Jupyter Notebook
* Data visualization
* Sports analytics

## How to Run

Clone the repository:

```bash
git clone https://github.com/963Salim/Champions-League-Old-and-New-Format-Analysis.git
```

Open the project folder:

```bash
cd Champions-League-Old-and-New-Format-Analysis
```

Install the required Python packages:

```bash
pip install pandas matplotlib seaborn jupyter
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Then open one of the notebooks:

```text
ChampionsLeagueOldFormat.ipynb
ChampionsLeagueNewFormat.ipynb
```

## Important Note

Some notebook cells may contain local file paths from the original development environment. If necessary, these paths should be adapted to the local folder structure after cloning the repository.

## Conclusion

This project demonstrates how Python and Jupyter Notebooks can be used to analyze and visualize changes in football tournament formats. It combines sports analytics, data visualization and structured comparison of tournament systems.
